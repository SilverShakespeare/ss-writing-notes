# 银莎的叙事写作指南

> 画面感 · 镜头感 · 叙事节奏：一套可操作的写作方法

**作者**：银色莎士比亚（Silver Shakespeare）
**版本**：2026.10

---

## 这是什么

一本面向叙事写作者的写作方法指南，围绕三条主线展开：

- **画面感**：如何用文字在读者脑中「成像」——具象化描写、修辞唤醒；
- **镜头感**：借鉴电影的镜头语言来组织描写——景别、聚焦与景深、镜头运动、镜头调度、蒙太奇、声画关系；
- **叙事节奏**：如何控制读者的「心理时间」——驱动性文本与渲染性文本的配比、五种基础节奏模式、加速与减速的用词倾向。

全书共 **7 编**，并附四份附录：**附录 A** 术语与理论对照（把书中的说法对接通行叙事学 / 电影学理论）、**附录 B** 速查表、**附录 C** 常见毛病与处方、**附录 D** 声明。
